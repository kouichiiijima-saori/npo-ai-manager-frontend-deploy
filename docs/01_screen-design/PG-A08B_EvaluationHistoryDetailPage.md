# 2. 画面概要

AI判定履歴の詳細を参照する。

AI判定時点の判定結果およびスナップショット情報を監査目的で保存・閲覧する。

本画面は参照専用画面であり、編集・削除は行わない。

---

# 6. 業務ルール

- AI判定履歴は監査ログとして扱う。
- 更新しない。
- 削除しない。
- 判定時点のスナップショットを保持する。
- 現在の団体情報変更の影響を受けない。
- 現在の活動実績変更の影響を受けない。
- 現在の助成金情報変更の影響を受けない。

---
